Étendue de la recherche

Par artistes : les tags décrivent l’artiste, pas nécessairement chacun de ses morceaux. Par morceaux : seuls les tags du titre sont utilisés, sans remplacement par ceux de l’artiste. « Tous les tags » vérifie leur présence parmi les tags principaux renvoyés par Last.fm. Les recherches composées (exemple : jazz punk, punk jazz) servent à découvrir des candidats supplémentaires ; un tag composé couvrant les termes demandés est également accepté (jazz punk, punk jazz ou jazz-punk pour jazz + punk). Les candidats communs sont examinés en priorité, avant application de la surprise dans chaque groupe. Le croisement reste limité aux candidats examinés. Le score d’affinité est un calcul de sélection, pas un nombre de votes ni une probabilité.
